## Rules that keep the page trusted

- Say "tendency" and "traditionally", never promise results.
- Never post fear-based lines like "bad time coming".
- Reply to every comment in the first 2 hours of a post.
- Put the page link on every story with the link sticker.
- Use the share picture from the website, so each shared post carries kundlikaka.in.
